# TogetherServer 0.3.1 release

Date: 2026-10-09. Status: **published and publicly verified**. [Release and downloads](https://github.com/daltonstates/TogetherServer/releases/tag/v0.3.1), release ID `408409436`. The owner authorized publication after pushing `main`. Production's running app and data were not updated.

## Changes and compatibility

This release includes the unreleased work since `v0.3.0`: signed server chat and notices, protected/named backups, pre-join requirements and fixed client-opening/manual fallback, guided settings, local runtime summaries, shared-save workflows with explicit permissions, diagnostics and recovery, and Host/Join/backup/header UI changes. Real-game live save remains disabled pending per-game acceptance; Minecraft fixture support and Factorio/Terraria preview boundaries remain unchanged. See [the UI audit](17-UI-STRUCTURE-AND-FLOW.md) for the screen inventory, moved-feature map, reusable rules and rendered comparisons.

Both published 0.3.0 and 0.3.1 use companion protocol 3. **Actual binaries passed both role directions**: 0.3.1 Host / 0.3.0 Friend and 0.3.0 Host / 0.3.1 Friend. Coverage includes authenticated/pinned pairing, exact versions, assigned status, remote Start/Ready, positive-count Stop denial, fresh-zero graceful Stop, paused-control status, assignment enforcement, saved-access restart and revocation. The legacy EXE was downloaded from the published release and checked against SHA-256 `e2741b7425c497a7850bc95b5b844a4503099bf6a575484476b4a37330cdce8e`. New features still require their advertised capabilities; this does not establish every new feature on an older peer.

Local state advances storage schema 2 to 4 and pairing schema 2 to 3. The old executable cannot open the migrated directory; restoring `.previous` alone is not a data rollback. The actual published 0.3.0 parent/new-helper handoff passed on disposable data: readiness was signalled before parent exit, the exact candidate was installed, the exact old EXE was retained, `idleMinutes=42` survived, the storage marker migrated, and the new app relaunched/quit through its guarded API.

Release review found and fixed the helper rejecting schema-2 checkpoints. Helper-only validation accepts supported source schemas 2–4 with a forward target version, previous EXE binding, matching explicit source/checkpoint markers and the existing root/hash/name/size/tamper checks. Normal current-app checkpoint callers still require the current schema. Pure regressions, same-candidate handoff and actual old-to-new handoff passed.

Browser/OS zoom beyond app text presets, exhaustive contrast and the Settings sticky-offset concern remain separate UI checks. Local symbolic-link subcases were skipped for the account lacking that capability. The existing Vite chunk-size advisory remains. Production PID `51404` and its published 0.3.0 EXE hash were unchanged throughout this work.
