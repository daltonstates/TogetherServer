# TogetherServer 0.3.3.1 prerelease

Owner authorization, 2026-10-21: publish the current simplified shared-hosting
feature to GitHub as a prerelease numbered `0.3.3.1`. Stable/latest remains
`v0.3.3`. The application, UI manifest/lockfile and installer default are aligned
to the requested four-component version.

## Scope

This preview replaces ordinary save-sharing, forwarding and hosting-management
choices with one original-Host switch and a permitted Friend's Host locally
action. Save synchronization, integrity and signed-descendant selection are
automatic. A returning original owner follows newer verified progress without
overwriting the original world. Conflicting or incomplete known newest saves
block hosting safely. See the [feature delivery record](36-SHARED-HOSTING-SIMPLIFICATION.md).
