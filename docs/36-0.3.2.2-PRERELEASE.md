# TogetherServer 0.3.2.2 prerelease

Prepared: 2026-10-19. Status: **validation pending; not published**.

The owner authorized a new GitHub preview release and only a one-step increase
to the smallest version component: `0.3.2.1` to `0.3.2.2`, tag `v0.3.2.2`.
Application and UI manifest/lockfile versions are aligned. Publication must use
`prerelease=true` and `make_latest=false`; stable/latest remains `v0.3.2`.

## Included changes

- Simpler shared-save permissions and local hosting preparation.
- Planned hosting moves to an approved paired PC, with recipient Accept/Decline
  and guided preparation. Final-save verification and manual destination Start
  remain required.
- Quieter routine player checks and clearer everyday wording.
- Resizable page sidebars, shared scrollbar styling and improved spacing.
- Native taskbar, maximize, tray and titlebar double-click corrections.

## Release validation

Local verification is limited to `scripts/verify-code-only.ps1`, safe source
checks and static artifact inspection. No packaged app, game, fixture, browser,
installer or native-input automation may run on the owner's active desktop.

A fresh immutable candidate must pass the full Windows CI suites, mixed-version
checks and installer smoke on dedicated hosted runners before publication.
The installer must embed the same portable bytes. Publish the portable and
installer EXEs with their adjacent SHA-256 files, then download all four assets
anonymously and verify hashes, sizes, versions and release classification.
Record the exact source, run, artifact and digest identities here when complete.

The local code-only gate passed all 57 source/synthetic groups, pinned locked
dependency restores, TypeScript, lint and solution compilation with zero
warnings/errors. Its existing source-link subcase is skipped because this
Windows account cannot create symbolic links. The updated companion runner also
compiled with zero warnings/errors. These checks launched no app or fixture.

Release preparation found obsolete picker/navigation and draft wording in the
browser/native harnesses and five removed text expectations in the served-UI
scanner. The checks now follow the current server directory and copy while
retaining lifecycle, permissions, draft durability, exact profile and cleanup
assertions. The browser harness also exercises the rendered sidebar divider and
remembered selection, tab and width. Syntax checks pass; runtime results remain
pending. Existing C# whitespace drift is normalized for the required formatter;
the C# formatting changes contain no non-whitespace edits. The served-UI static
check also found four native controls bypassing the existing shared components
in the server directory and development demo. Those now use the shared controls
with their existing labels, values and callbacks.

Final local formatting verification passed. The production UI bundle and all
served-UI static assertions passed against fresh JS/CSS; the existing large-chunk
warning remains. All 26 existing server-directory/development-demo UI tests
passed. Hosted runtime acceptance, packaging and publication are still pending.

The hosted workflow now includes published `0.3.2.1` in both mixed-version
directions and update handoff, with its independently checked GitHub digest and
schema 5-to-5 data preservation. Earlier stable compatibility lanes remain.
The Desktop lane also runs the current taskbar/tray/titlebar smoke against the
same candidate. Update handoff alone does not prove live GitHub discovery or
the in-app update review flow.

## Acceptance boundaries

This preview uses the normal production data directory. It is separate from the
isolated development/staging app. The published 0.3.2 updater cannot discover
four-part tags, so those users must install this preview directly. Preview
enrollment remains per PC and installation requires **Update and restart**.

Hosted and synthetic results do not establish real Friend-PC/WAN access, game
joins, recognizable world-save integrity or real game restart recovery.
Minecraft remains fixture-tested; Factorio and Terraria remain previews.
Unsigned executables must be identified as such without a publisher-trust claim.
