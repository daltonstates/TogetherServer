Owner authorization, 2026-10-24: create a new GitHub prerelease for the
[remote-hosting fixes](50-REMOTE-HOSTING-HISTORY-PROGRESS-AND-OWNER-STOP.md).

must produce one immutable Windows candidate. Hosted functional, rendered,
compatibility, native and installer checks consume those unchanged bytes.

the frozen candidate, installer and adjacent SHA-256 files.
