Owner authorization, 2026-10-23: create a new prerelease for the local-hosting
copy and access feedback repair in [delivery record 48](48-LOCAL-HOSTING-COPY-AND-ACCESS-FEEDBACK.md).

## Behavior

Opening Host locally distinguishes preparation that has not run from an
established missing save or failed transfer. A received payload and its signed
announcement still cannot become a prepared hosting copy without the full
file and signed-history checks. The guide preserves actual copy failure
messages, recommends Share latest backup for an existing completed backup and
asks for graceful Stop only when no completed backup exists.

The Friend page explains whether hosting access is being checked, denied or
unavailable. Unavailable and history-review results offer a fixed read-only
retry. Host locally still requires a current verified grant; retry never
prepares a copy, enables a listener or starts a game. Late and old-connection
responses cannot restore permission or repeat Start.

checkout. One clean committed source produces one immutable Windows candidate;
hosted functional, browser, compatibility, native and installer jobs consume
those unchanged bytes. Local checks never launch the app, game, browser,
console fixture or installer.

The underlying repair passes 279 focused UI tests in four files, all 66

Exact source, run, artifact identities and acceptance results will be recorded

fixture-tested. Publication is a prerelease and must leave stable/latest and
all previous release assets unchanged.
