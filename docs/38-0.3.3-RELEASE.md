# TogetherServer 0.3.3 stable release

Authorized on 2026-10-20 as the next stable release after 0.3.2. This is a
three-component version so the published stable updater can discover it.
The current source includes the later preview features and setup/shared-hosting
work. Publication is pending validation; this document does not mark it released.

## Included changes

- One server directory for local and Friend servers, with searchable,
  adjustable sidebars and clearer navigation.
- First-use Host/Join guides, required profile names, continuous App Settings,
  clearer Friend permissions, and separate game-password access.
- Shared-save permissions and guided hosting preparation, signed peer
  discovery, planned paired-PC hosting requests with Accept/Decline, and
  explicit destination Start.
- Backup-library and protection controls, reviewed game settings/files,
  protected drafts, chat notices, and quieter routine player checks.
- Windows tray, taskbar, titlebar, notifications, and actual installer wizard
  corrections documented in their feature records.
- Rewritten README and task-based user/developer documentation.

Feature details and their original evidence remain in the
[documentation index](README.md). This release needs its own immutable candidate
and exact-byte acceptance; earlier passes are not tests of the new binary.

## Preparation

Application, UI manifest/lockfile, and installer default are set to 0.3.3.
Compatibility and update handoff include all five published 0.3.x versions,
through 0.3.2.2, in both Host/Friend directions and applicable schema migration.

The earlier native gate was blocked by actual Windows QuietTime on a new
hosted profile. The Desktop job now waits at most 65 minutes for the real
Windows API to return AcceptsNotifications before the unchanged notification
delivery/click checks. It does not alter settings, registry, clock, or the
application's notification policy. Native window checks run first. All required
native cases remain mandatory; failure or persistent suppression blocks packaging.
Microsoft documents the first-login period in
[QUERY_USER_NOTIFICATION_STATE](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ne-shellapi-query_user_notification_state).

## Acceptance boundaries

The owner's active desktop and running production app are outside automated
runtime testing. Local work is code-only and static inspection; process,
browser, native, and installer checks run only on separate hosted Windows.
No production world, installation, credential, firewall, router, or DNS changes
are authorized by this release work.

Hosted/synthetic results do not establish physical Friend-PC/WAN routes, real
game joins, or recognizable save/load/restart integrity. Minecraft remains
fixture-tested. Factorio and Terraria remain previews; Terraria's unknown count
blocks Friend and automatic Stop. Live-save publication requires exact installed
setup acceptance. Unsigned assets have GitHub digest verification, not verified
Windows publisher or SmartScreen trust.

Updating stable 0.3.2 data advances storage schema 4 to 5. Existing pairings,
settings, and worlds remain; rolling back requires a complete matching
pre-migration data backup, never a lowered marker. Preview enrollment remains
per PC, and installation still requires **Update and restart**.
